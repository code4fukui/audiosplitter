# audiosplitter

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

MP3 silence splitter and time record output.

## Features
- Split MP3 files by silence
- Output segments as MP3 files
- Generate CSV file with start and end times of each segment

## Usage
1. Select an MP3 file
2. Adjust the silence threshold and minimum silence duration
3. Click the "Download" button to download a ZIP file containing the split segments and a CSV file with the time records
